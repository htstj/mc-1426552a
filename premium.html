本機勾選與備份

資料只存在這個瀏覽器。換裝置、清除瀏覽器資料，或一段時間沒用時，資料可能不見。請定期按「匯出備份」。我們無法替你復原。

勾選與下方備註只會自動保存在這個瀏覽器的本機儲存，本工具不會把它們上傳到任何伺服器（點開法規連結時，會像一般上網一樣連到該網站）。建議用電腦瀏覽器為主；手機請用 Safari 或 Chrome 開啟本檔。

匯出檔為 JSON，檔名含日期。匯入前會再確認是否覆蓋。備份檔含你填的備註，請自行妥善保存。

如何開啟（電腦／手機）

建議：電腦瀏覽器

  1. 把本 HTML 檔下載到電腦。
  2. 用 Chrome、Edge、Firefox 或 Safari 直接開啟檔案（雙擊或拖進視窗）。
  3. 開始勾選；需要換機或備份時，按「匯出備份」。

iPhone／iPad（Safari）

  1. 先把檔案存到「檔案」App（例如下載項目或 iCloud Drive）。
  2. 若分享選單中有「Safari」或「用 Safari 開啟」，請選它開啟；若沒有，建議改用電腦瀏覽器，或在手機上閱讀手機版 PDF。
  3. 在 Safari 裡勾選與備份。請定期按「匯出備份」。

說明：僅用「檔案」App 點開預覽，可能無法勾選或儲存；請改以 Safari 開啟。

Android（Chrome）

  1. 用 Chrome 下載本 HTML，或從「檔案」選取後以 Chrome 開啟。
  2. 在 Chrome 中勾選；請定期按「匯出備份」。

Excel 追蹤表建議在電腦上設定與使用；手機端主要用來查看。

E. 登記日／假日／熱門日時程尺

工具目的

協助使用者依照預約規則，反向安排想要的結婚登記日期。

這份工具不是預約系統，不會代替使用者取得預約名額，也不代表特定日期一定可以受理。

熱門日提醒：如 520 等易滿時段僅作提醒，以該戶政事務所公告為準；非法律規定。

關於「三十日目標日」欄（對應 Excel「時程規劃」）：僅適用國外結婚已生效後之結婚登記——自國外結婚生效日起算 30 日（戶政司 Q06：https://www.ris.gov.tw/documents/html/8/7/1/150_Q06.html）。國內結婚請留空本欄；國內結婚於完成結婚登記時生效。

第三步：由預定日期往前回推

操作方法：

  1. 找出預定登記日期。
  2. 確認該日期屬於一般辦公日或假日辦理。
  3. 開啟預約說明頁。
  4. 依適用的預約規則，計算預約開放區間。
  5. 確認最晚申請時間。
  6. 將預約開放時間記入自己的行事曆。
  7. 於入口自行完成預約。
  8. 保存預約結果。

第四步：指定登記日的安排

依戶政司說明，結婚當事人除於結婚登記當日親自到戶政事務所辦理者外，得於結婚登記日前3個辦公日內指定結婚登記日。

應另外確認指定登記日與網路預約的適用方式，不要將兩項規則直接視為同一程序。

F. 婚後多機關變更追蹤—使用說明

工具目的

結婚登記完成後，可能還有多個機關及民間機構需要更新資料。

本工具將常見項目集中管理，避免只完成戶籍資料更新，卻忽略其他資料。對應 Excel「機關變更」工作表。

建議使用方式

1. 先建立變更清單

依實際情況檢查：

  • 戶政資料
  • 身分證明文件
  • 健保
  • 勞保
  • 所得稅
  • 銀行帳戶
  • 信用卡
  • 保險（姓名、聯絡資料；不含受益人建議）
  • 證券帳戶
  • 電信
  • 水電瓦斯
  • 房屋相關資料（聯絡、帳單資料）
  • 汽機車相關資料
  • 雇主人事資料
  • 其他會員資料

2. 判斷是否需要處理

每個項目可設定：

  • 不適用
  • 尚未確認
  • 待辦
  • 已聯絡
  • 已送件
  • 已完成

以上是工具內部的管理狀態，不代表機關正式案件狀態。

3. 記錄聯絡資訊

每次與機關或業者聯絡，可記錄：

  • 聯絡日期
  • 聯絡單位
  • 聯絡方式
  • 承辦單位提供的說明
  • 應備資料
  • 後續處理事項
  • 自行設定的追蹤日期

4. 完成後留存紀錄

建議保留：

  • 申請或送件紀錄
  • 完成通知
  • 資料更新確認
  • 相關收據或證明

是否需要留存、保存方式及期限，依各機關或業者規定。

追蹤原則

不要假設戶籍資料更新後，所有機關都會自動同步。

每個項目應以實際受理單位回覆為準。

J. 兩人／家人分工表—使用說明與示例任務列

工具目的

讓婚姻登記及婚後行政事項有明確負責人，避免兩人都以為對方已經處理。對應 Excel「分工」工作表。

可依需要由兩人共同使用，也可加入家人協助的工作項目。

建議分工原則

  1. 每個任務指定一位主要負責人。
  2. 重要文件由另一人協助複核。
  3. 需要本人辦理的事項，先確認本人是否能配合。
  4. 由負責人記錄進度。
  5. 已完成事項留下必要紀錄。
